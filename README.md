# UCSB CS 130A — Data Structures and Algorithms

Coursework for UCSB Computer Science 130A, with emphasis on data structures, algorithm analysis, hashing, and graph algorithms.

## Project

- **Bloom Filter** — implementation and experiments comparing hash functions, false positive rates, and table occupancy. Source code is kept in a private repository linked as the `BloomFilter` submodule.

This course repository is an index for substantial projects. Individual homework submissions and lecture materials are not included.
